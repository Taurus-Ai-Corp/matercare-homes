## License Tiers

### Tier 1: Community Edition (MIT)
**Price**: Free  
**Target**: Individual caregivers, small home setups

Included:
- Core AI assistant (limited queries)
- Basic sensor gateway
- Standard knowledge base
- Community support

Restrictions:
- Max 1 senior monitored
- 100 AI queries/month
- No commercial use

### Tier 2: Professional ($29/month)
**Target**: Family caregivers, small agencies

Included:
- Everything in Community
- Unlimited AI queries
- Up to 5 seniors
- SMS alerts
- Priority support

### Tier 3: Enterprise ($199/month)
**Target**: Senior living facilities, home care agencies

Included:
- Everything in Professional
- Unlimited seniors
- Custom integrations
- API access
- Dedicated support
- SLA guarantee

### Tier 4: White-Label (Custom)
**Target**: Healthcare companies, insurers

Included:
- Full source code access
- Custom branding
- On-premise deployment
- Dedicated infrastructure
- Custom SLAs
- Revenue share options
